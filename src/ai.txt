7. I asked "Why does one of my two columns become narrower than the other on mobile even though both have flex: 1?" Gemini explained that flex items have a default min-width of auto, meaning they will not shrink below the width of their longest content even if flex: 1 is set. This caused the columns to be unequal widths. The fix was adding min-width: 0 to .log-column, which allows the column to shrink freely and makes both columns equal on mobile.
8. I asked "How do I style my checkboxes to use my app's green color instead of the default blue?" Gemini introduced the accent-color CSS property, explaining it is the standard way to tint native form controls like checkboxes without replacing them with custom elements. I added accent-color: #606C38 to the checkbox styles so all checkboxes in the form match the rest of the app's color scheme.

Since my app is specifically for Hsinchu Taiwan family where my pomeranian resides in, I asked "How do I request only specific weather fields from the Open-Meteo API instead of getting the entire response?" Gemini explained that Open-Meteo uses URL query parameters to control what data is returned, and that adding current=temperature_2m,relative_humidity_2m to the URL tells the API to include only those two fields. It also explained that the values come back nested inside a current object, so I access them as weatherData.current.temperature_2m and weatherData.current.relative_humidity_2m.
